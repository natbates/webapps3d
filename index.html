Interface Notes

This starter site uses Three.js to render a 3D scene inside a responsive web page. It includes model selection, lighting controls, and wireframe toggling.

  • Three.js 3D viewport with interactive controls
  • Model gallery with three placeholder models
  • Wireframe toggle for debugging geometry
  • Light intensity and color controls
  • Content swapping via JavaScript tabs

Use this scaffold to replace placeholder models with your own glTF/GLB assets exported from Blender or 3ds Max.
