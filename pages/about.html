About this 3D App

This website is built to satisfy the assignment requirements for a 3D application using HTML5, CSS3, and JavaScript. It demonstrates how to load and swap models, control lighting, and provide a responsive interface.

How the app is structured

  • A responsive page layout with a header, control panel, viewer, and media section.
  • A Three.js viewport that can show different 3D objects.
  • UI controls for switching models, toggling wireframe mode, and adjusting light properties.
  • A separate section for content and references.

Model creation roadmap

  1. Design and create at least three models in Blender or 3ds Max.
  2. Refine geometry, add realistic materials, and UV unwrap each model.
  3. Apply texture maps for labels, brand details, and product finishes.
  4. Export each model as glTF / GLB for Three.js compatibility.
  5. Replace the placeholder objects in js/app.js with real loaded models from the assets/resources/models/ folder.

Recommended submission approach

Keep the website files and 3D sources together. Use GitHub for version control and as your submission archive. Include Blender or 3ds Max source files, exported glTF/GLB models, and a short README describing each model.

Remember: do not publish your final submission on external ISP sites. Use the university server, Canvas zip upload, or GitHub archive.
