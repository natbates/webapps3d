# Web3D App Demo

This starter website implements the basic assignment requirements for a 3D web application.

## What is included

- `index.html` — main page with Three.js viewport, model selection and controls
- `about.html` — assignment notes, model creation plan, and submission guidance
- `styles.css` — responsive layout and modern UI styling
- `app.js` — Three.js scene setup, model gallery, wireframe toggle, lighting controls, and animation
- `models/` — placeholder directory for exported model assets

## How to use

1. Open `index.html` in a browser.
2. Use the model buttons to switch between objects.
3. Toggle wireframe mode, change light intensity, and adjust light color.
4. Click the 3D object or press the animation button to animate it.

## Next steps for model creation

1. Create at least three 3D models in Blender or 3ds Max.
2. Refine geometry, UV unwrap, and apply textures for branding.
3. Export the final models as `glTF` / `GLB`.
4. Store exports in the `models/` folder and update `app.js` to load them with `GLTFLoader`.
5. Keep your `.blend` or 3ds Max archive in the same project for submission.

## Submission notes

- Do not publish the final submission on any external ISP site.
- Use a Canvas zip upload, a OneDrive folder, or a GitHub archive.
- Include source model files and exported 3D assets.
